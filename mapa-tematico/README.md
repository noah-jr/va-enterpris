## 🎯 Funcionalidades
 
 ### 🚨 Gestão de Emergências (SOS)
 Quando um passageiro ou motorista ativa o botão de pânico (**SOS**), este painel recebe um alerta prioritário com:
 - **Localização exata** no mapa.
 - **Áudio em tempo real** do ambiente (se disponível).
 - **Dados dos envolvidos** (perfil, veículo, histórico).
 
 ### 📊 Monitorização e Auditoria
 - Visão global de todas as viagens ativas em Luanda.
 - Histórico de incidentes e resoluções.
 - Logs detalhados de todas as ações administrativas.
 
 ## 🛠️ Tecnologias
 
 - **Next.js 15** (Core)
 - **Tailwind CSS** (Interface Premium)
 - **Lucide icons** (Iconografia consistente)
 - **Socket.IO** (Alertas instantâneos)
 
 ## 📦 Instalação
 
 ```bash
 cd addons/cisp-admin
 npm install
 npm run dev
 ```
